Reference imagery used by the FIELD handbook

Every image file in this directory must appear below with a creator, a licence and a source URL.
A test enforces that: marketing-minthep/scripts/test_tools.py, in
test_every_reference_image_has_a_licence_line. A file here without a licence line fails the suite,
so an image cannot enter this directory by being convenient.

Seventeen files were removed from here on 2026-07-29. They were photographs of named living people,
saved from Instagram, and their stated licence was "copyright remains with the original creators" —
which is not permission to republish them on a public site. The skill's own
references/creative-evaluation.md rejects any asset whose source rights are unresolved, so a demo
page shipping seventeen of them was arguing against itself. What they stood in for is now drawn
instead: ../generated/refsheet-reference.svg, built by
`marketing-minthep/scripts/render_refsheet.py --sheet reference`, shows the same borrowed picture
twice — once as the parts that belong to somebody, once as the geometry that belongs to nobody.

These three illustrate reference-role analysis only. The skill defaults to extracting
non-identifying composition, lighting, styling, pose, wardrobe, and color qualities for original
fictional subjects; it does not imply endorsement by the depicted people, and it will not reproduce
a real person's face.

Generated concept samples under ../generated/ are either drawn by code or were created on
2026-07-22 for handbook demonstration. They depict fictional concepts and must not be represented
as real products, endorsements, or photographed people. The refsheet-*.svg and bun-bo-*.svg files
are drawn by scripts under marketing-minthep/scripts/ from the tables under
marketing-minthep/data/, and contain no photography at all.
